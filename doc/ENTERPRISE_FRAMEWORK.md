## What is the Enterprise Framework?

The Enterprise Framework is a set of **base classes and interfaces** that provide common enterprise functionality out of the box. It's automatically included in every microservice generated by Enterprise CLI.

**Key Philosophy:** *Don't repeat yourself*. Write business logic, not boilerplate.

### Problems It Solves

❌ **Without Enterprise Framework:**
- Write CRUD operations for every entity
- Implement audit logging manually
- Handle soft deletes everywhere
- Duplicate transaction management
- Copy-paste validation logic
- Repeat exception handling

✅ **With Enterprise Framework:**
- CRUD operations inherited
- Audit fields automatic
- Soft delete built-in
- Transactions managed
- Validation hooks provided
- Consistent error handling

## AbstractEnterpriseEntity

**Location:** `src/main/java/{package}/enterprise/framework/entity/`

### What It Provides

All generated entities extend this base class to get:

1. **Primary Key**
   - `Long id` with auto-generation

2. **Audit Fields**
   - `LocalDateTime createdAt` - When created
   - `LocalDateTime updatedAt` - When last modified
   - `String createdBy` - Who created (from security context)
   - `String updatedBy` - Who last modified

3. **Soft Delete**
   - `Boolean deleted` - Mark as deleted without removing from DB
   - Automatic exclusion from queries

4. **Optimistic Locking**
   - `@Version Long version` - Prevent concurrent modification issues

### Code Example

```java
@MappedSuperclass
public abstract class AbstractEnterpriseEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @CreatedDate
    @Column(nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @LastModifiedDate
    @Column(nullable = false)
    private LocalDateTime updatedAt;

    @CreatedBy
    @Column(nullable = false, updatable = false)
    private String createdBy;

    @LastModifiedBy
    @Column(nullable = false)
    private String updatedBy;

    @Column(nullable = false)
    private Boolean deleted = false;

    @Version
    private Long version;

    // Getters and setters...

    @PrePersist
    protected void onCreate() {
        createdAt = LocalDateTime.now();
        updatedAt = LocalDateTime.now();
        if (deleted == null) {
            deleted = false;
        }
    }

    @PreUpdate
    protected void onUpdate() {
        updatedAt = LocalDateTime.now();
    }
}
```

### Your Entity Example

```java
@Entity
@Table(name = "users")
public class User extends AbstractEnterpriseEntity {

    @Column(nullable = false, unique = true)
    private String email;

    @Column(nullable = false)

    private String lastName;

    @Enumerated(EnumType.STRING)
    private UserStatus status;

    // Only define YOUR business fields!
    // id, audit fields, soft delete are inherited
}
```

## AbstractEnterpriseRepository

**Location:** `src/main/java/{package}/enterprise/framework/repository/`

### What It Provides

All repositories extend this interface to get:

1. **Standard CRUD Methods**
   - `findAll()` - List all (excluding deleted)
   - `findById(Long id)` - Find by ID
   - `save(T entity)` - Create or update
   - `delete(Long id)` - Soft delete
   - `hardDelete(Long id)` - Permanently delete
   - `findAllIncludingDeleted()` - Include soft-deleted

2. **Pagination Support**
   - `findAll(Pageable pageable)` - Paginated results

3. **Soft Delete Handling**
   - Automatic filtering of deleted records
   - Can override to include deleted if needed

### Code Example

```java
@NoRepositoryBean
public interface AbstractEnterpriseRepository<T extends AbstractEnterpriseEntity, ID>
    extends JpaRepository<T, ID> {

    /**
     * Find all non-deleted entities
     */
    @Query("SELECT e FROM #{#entityName} e WHERE e.deleted = false")
    List<T> findAll();

    /**
     * Find by ID, excluding deleted
     */
    @Query("SELECT e FROM #{#entityName} e WHERE e.id = :id AND e.deleted = false")
    Optional<T> findById(@Param("id") ID id);

    /**
     * Soft delete
     */
    @Modifying
    @Query("UPDATE #{#entityName} e SET e.deleted = true WHERE e.id = :id")
    void softDelete(@Param("id") ID id);

    /**
     * Find all including deleted
     */
    @Query("SELECT e FROM #{#entityName} e")
    List<T> findAllIncludingDeleted();
}
```

### Your Repository Example

```java
@Repository
public interface UserRepository extends AbstractEnterpriseRepository<User, Long> {

    // Only add YOUR custom queries!

    Optional<User> findByEmail(String email);

    List<User> findByStatus(UserStatus status);

    @Query("SELECT u FROM User u WHERE u.lastName LIKE %:name%")
    List<User> findByLastNameContaining(@Param("name") String name);
}
```

## AbstractEnterpriseService

**Location:** `src/main/java/{package}/enterprise/framework/service/`

### What It Provides

All services extend this base class to get:

1. **Transaction Management**
   - All methods run in transactions automatically
   - Rollback on exceptions

2. **Standard Operations**
   - `findAll()` - List all
   - `findById(Long id)` - Get by ID
   - `create(T entity)` - Create new
   - `update(Long id, T entity)` - Update existing
   - `delete(Long id)` - Soft delete

3. **Validation Hooks**
   - `validateCreate(T entity)` - Override for create validation
   - `validateUpdate(T entity)` - Override for update validation
   - Throws `BusinessValidationException` on errors

4. **Event Publishing**
   - `publishEvent(DomainEvent event)` - Publish domain events
   - Events for create, update, delete

### Code Example

```java
@Service
@Transactional
public abstract class AbstractEnterpriseService<T extends AbstractEnterpriseEntity, ID> {

    protected final AbstractEnterpriseRepository<T, ID> repository;
    protected final ApplicationEventPublisher eventPublisher;

    public AbstractEnterpriseService(
        AbstractEnterpriseRepository<T, ID> repository,
        ApplicationEventPublisher eventPublisher
    ) {
        this.repository = repository;
        this.eventPublisher = eventPublisher;
    }

    public List<T> findAll() {
        return repository.findAll();
    }

    public T findById(ID id) {
        return repository.findById(id)
            .orElseThrow(() -> new EntityNotFoundException("Entity not found: " + id));
    }

    public T create(T entity) {
        validateCreate(entity);
        T saved = repository.save(entity);
        publishEvent(new EntityCreatedEvent(saved));
        return saved;
    }

    public T update(ID id, T entity) {
        T existing = findById(id);
        validateUpdate(entity);
        entity.setId(id);
        T updated = repository.save(entity);
        publishEvent(new EntityUpdatedEvent(updated));
        return updated;
    }

    public void delete(ID id) {
        T entity = findById(id);
        repository.softDelete(id);
        publishEvent(new EntityDeletedEvent(entity));
    }

    // Override these in your service for custom validation
    protected void validateCreate(T entity) {
        // Default: no validation
    }

    protected void validateUpdate(T entity) {
        // Default: no validation
    }

    protected void publishEvent(DomainEvent event) {
        eventPublisher.publishEvent(event);
    }
}
```

### Your Service Example

```java
@Service
public class UserService extends AbstractEnterpriseService<User, Long> {

    private final UserRepository userRepository;

    public UserService(
        UserRepository userRepository,
        ApplicationEventPublisher eventPublisher
    ) {
        super(userRepository, eventPublisher);
        this.userRepository = userRepository;
    }

    // Add YOUR business logic methods

    public User findByEmail(String email) {
        return userRepository.findByEmail(email)
            .orElseThrow(() -> new EntityNotFoundException("User not found: " + email));
    }

    public List<User> findByStatus(UserStatus status) {
        return userRepository.findByStatus(status);
    }

    @Override
    protected void validateCreate(User user) {
        // Your custom validation
        if (userRepository.findByEmail(user.getEmail()).isPresent()) {
            throw new BusinessValidationException("Email already exists: " + user.getEmail());
        }

        if (!user.getEmail().matches("^[A-Za-z0-9+_.-]+@(.+)$")) {
            throw new BusinessValidationException("Invalid email format");
        }
    }

    @Override
    protected void validateUpdate(User user) {
        // Your custom validation
        if (user.getStatus() == UserStatus.ARCHIVED) {
            throw new BusinessValidationException("Cannot update archived user");
        }
    }
}
```

## AbstractEnterpriseController

**Location:** `src/main/java/{package}/enterprise/framework/controller/`

### What It Provides

All controllers extend this base class to get:

1. **Standard REST Endpoints**
   - `GET /api/v1/{resource}` - List all
   - `GET /api/v1/{resource}/{id}` - Get by ID
   - `POST /api/v1/{resource}` - Create
   - `PUT /api/v1/{resource}/{id}` - Update
   - `DELETE /api/v1/{resource}/{id}` - Delete

2. **Exception Handling**
   - Automatic conversion to proper HTTP status codes
   - Consistent error response format

3. **Response Wrapping**
   - Standard `ResponseEntity<T>` wrapping
   - Proper HTTP status codes

### Code Example

```java
@RestController
public abstract class AbstractEnterpriseController<T extends AbstractEnterpriseEntity, ID> {

    protected final AbstractEnterpriseService<T, ID> service;

    public AbstractEnterpriseController(AbstractEnterpriseService<T, ID> service) {
        this.service = service;
    }

    @GetMapping
    public ResponseEntity<List<T>> findAll() {
        return ResponseEntity.ok(service.findAll());
    }

    @GetMapping("/{id}")
    public ResponseEntity<T> findById(@PathVariable ID id) {
        return ResponseEntity.ok(service.findById(id));
    }

    @PostMapping
    public ResponseEntity<T> create(@Valid @RequestBody T entity) {
        T created = service.create(entity);
        return ResponseEntity.status(HttpStatus.CREATED).body(created);
    }

    @PutMapping("/{id}")
    public ResponseEntity<T> update(@PathVariable ID id, @Valid @RequestBody T entity) {
        T updated = service.update(id, entity);
        return ResponseEntity.ok(updated);
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> delete(@PathVariable ID id) {
        service.delete(id);
        return ResponseEntity.noContent().build();
    }
}
```

### Your Controller Example

```java
@RestController
@RequestMapping("/api/v1/users")
public class UserController extends AbstractEnterpriseController<User, Long> {

    private final UserService userService;

    public UserController(UserService userService) {
        super(userService);
        this.userService = userService;
    }

    // Add YOUR custom endpoints

    @GetMapping("/email/{email}")
    public ResponseEntity<User> findByEmail(@PathVariable String email) {
        return ResponseEntity.ok(userService.findByEmail(email));
    }

    @GetMapping("/status/{status}")
    public ResponseEntity<List<User>> findByStatus(@PathVariable UserStatus status) {
        return ResponseEntity.ok(userService.findByStatus(status));
    }

    @PostMapping("/{id}/activate")
    public ResponseEntity<User> activateUser(@PathVariable Long id) {
        User user = userService.findById(id);
        user.setStatus(UserStatus.ACTIVE);
        return ResponseEntity.ok(userService.update(id, user));
    }
}
```

## Business Validation

The framework provides hooks for business validation.

### ValidationException

```java
public class BusinessValidationException extends RuntimeException {
    private final List<String> errors;

    public BusinessValidationException(String message) {
        super(message);
        this.errors = List.of(message);
    }

    public BusinessValidationException(List<String> errors) {
        super(String.join(", ", errors));
        this.errors = errors;
    }

    public List<String> getErrors() {
        return errors;
    }
}
```

### Using Validation

```java
@Override
protected void validateCreate(User user) {
    List<String> errors = new ArrayList<>();

    if (user.getEmail() == null || user.getEmail().isBlank()) {
        errors.add("Email is required");
    }

    if (user.getAge() != null && user.getAge() < 18) {
        errors.add("User must be 18 or older");
    }

    if (!errors.isEmpty()) {
        throw new BusinessValidationException(errors);
    }
}
```

## Benefits

### 60-70% Less Boilerplate

**Without Framework:**
```java
// UserController.java - 150 lines
// UserService.java - 200 lines
// UserRepository.java - 50 lines
// Total: 400 lines of boilerplate
```

**With Framework:**
```java
// UserController.java - 50 lines (only business logic)
// UserService.java - 80 lines (only business logic)
// UserRepository.java - 10 lines (only custom queries)
// Total: 140 lines
```

### Consistency

- All entities have same audit structure
- All services handle transactions the same way
- All controllers return consistent responses
- Errors handled uniformly

### Maintainability

- Fix bugs in framework → all services benefit
- Add features to framework → all services get them
- Easier onboarding for new developers

## Best Practices

### 1. Always Call Super Methods

```java
@Override
protected void validateCreate(User user) {
    super.validateCreate(user);  // Call parent first
    // Your validation
}
```

### 2. Keep Business Logic in Services

❌ **Don't:**
```java
@GetMapping("/activate/{id}")
public ResponseEntity<User> activate(@PathVariable Long id) {
    User user = userService.findById(id);
    user.setStatus(UserStatus.ACTIVE);  // Business logic in controller!
    return ResponseEntity.ok(userService.update(id, user));
}
```

✅ **Do:**
```java
// In UserService
public User activateUser(Long id) {
    User user = findById(id);
    user.setStatus(UserStatus.ACTIVE);
    return update(id, user);
}

// In UserController
@GetMapping("/activate/{id}")
public ResponseEntity<User> activate(@PathVariable Long id) {
    return ResponseEntity.ok(userService.activateUser(id));
}
```

### 3. Use DTOs for Complex Requests/Responses

```java
public record UserRegistrationRequest(
    String email,
    String firstName,
    String lastName,
    String password
) {}

public record UserResponse(
    Long id,
    String email,
    String fullName,
    UserStatus status
) {
    public static UserResponse from(User user) {
        return new UserResponse(
            user.getId(),
            user.getEmail(),
            user.getFirstName() + " " + user.getLastName(),
            user.getStatus()
        );
    }
}
```

### 4. Document Custom Endpoints

```java
@GetMapping("/email/{email}")
@Operation(summary = "Find user by email", description = "Returns a single user matching the email")
@ApiResponses({
    @ApiResponse(responseCode = "200", description = "User found"),
    @ApiResponse(responseCode = "404", description = "User not found")
})
public ResponseEntity<User> findByEmail(@PathVariable String email) {
    return ResponseEntity.ok(userService.findByEmail(email));
}
```

The Enterprise Framework provides:

✅ **AbstractEnterpriseEntity** - Audit, soft delete, versioning

✅ **AbstractEnterpriseService** - Business logic, transactions, validation, events
✅ **AbstractEnterpriseController** - REST endpoints, exception handling

**Your job:** Focus on business logic, not infrastructure.
